## E. Tax-deed property package — separate transaction file

For any future tax-deed acquisition, maintain a separate property-specific due-diligence package. Do not mix it into a general operating-loan request unless the lender expressly permits the use.

- [ ] Auction notice and sale rules.
- [ ] Parcel and property identification.
- [ ] Tax, lien, title, and legal research.
- [ ] Property condition and contractor estimates.
- [ ] Comparable sales and valuation support.
- [ ] Maximum bid and full acquisition budget.
- [ ] Exit / hold plan.
- [ ] Property-specific lender review.

## Security warning

The GitHub repository is public. Do not upload actual EIN letters, tax returns, bank statements, identity documents, Social Security numbers, full account numbers, credit reports, passwords, client records, or confidential partner agreements. Use the lender's verified secure portal for actual records.
