## GitHub Pages setup

In the repository, open **Settings → Pages**.

1. Under **Build and deployment**, choose **Deploy from a branch**.
2. Select branch `main`.
3. Select folder `/ (root)`.
4. Save and wait for the deployment to finish.
5. GitHub will display the published site URL in the Pages section.

## Public repository security notice

This repository is public. **Never commit**:
- EIN confirmation letters.
- Tax returns or bank statements.
- Social Security numbers or identity documents.
- Full account numbers, credit reports, passwords, API keys, or credentials.
- Client records, private leads, or confidential partner agreements.

Use a verified lender portal or another approved secure channel for actual financial and identity documents. This repository contains presentation materials, blank worksheets, and checklists only.
